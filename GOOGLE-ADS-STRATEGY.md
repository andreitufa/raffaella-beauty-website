### **Setup Google Ads Conversion Tag**

**Pași**:
1. Mergi la Google Ads → Tools → Conversions
2. Click "New conversion action"
3. Selectează "Website"
4. Configurează fiecare conversie conform listei de mai sus
5. Copiază Conversion ID și Conversion Label
6. Actualizează `components/GoogleAds.tsx` cu ID-urile reale

**Exemplu Cod**:
```typescript
// În components/GoogleAds.tsx
const GOOGLE_ADS_CONVERSION_ID = "AW-XXXXXXXXX"; // ID-ul tău
const GOOGLE_ADS_PHONE_CONVERSION_LABEL = "abc123";
const GOOGLE_ADS_WHATSAPP_CONVERSION_LABEL = "def456";
const GOOGLE_ADS_BOOKING_CONVERSION_LABEL = "ghi789";
```

## 📈 Optimizare & Monitoring

### **Metrici de Urmărit (Zilnic)**
1. ✅ **Impressions** - Câte persoane văd anunțurile
2. ✅ **Clicks** - Câte click-uri primești
3. ✅ **CTR (Click-Through Rate)** - Target: >3%
4. ✅ **CPC (Cost per Click)** - Target: 2-5 RON
5. ✅ **Conversions** - Câte conversii ai
6. ✅ **Cost per Conversion** - Target: 50-150 RON
7. ✅ **ROAS (Return on Ad Spend)** - Target: 3:1

### **Optimizări Săptămânale**
1. ✅ **Pause low performers** - Anunțuri cu CTR <1%
2. ✅ **Increase bids** - Pentru keywords performante
3. ✅ **Add negative keywords** - Exclude căutări irelevante
4. ✅ **Test new ad copy** - Creează variante noi
5. ✅ **Review search terms** - Adaugă keywords noi relevante

### **Optimizări Lunare**
1. ✅ **Review budget allocation** - Redistribuie bugetul către campaniile performante
2. ✅ **Expand successful campaigns** - Scale up ce funcționează
3. ✅ **Test new ad formats** - Responsive Search Ads, Call-only ads
4. ✅ **Review landing pages** - Optimizează pentru conversii mai bune
