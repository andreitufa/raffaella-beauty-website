# Vercel Analytics Setup - Raffaella Beauty

## 🎯 Ce vei vedea în Vercel Analytics:

### Trafic & Performanță
- **Page views**: vizualizări pagini în timp real
- **Unique visitors**: vizitatori unici
- **Top pages**: cele mai populare pagini
- **Referrers**: de unde vin vizitatorii
- **Countries**: din ce țări accesează

### Performance Metrics
- **Core Web Vitals**: viteza site-ului
- **First Contentful Paint**: cât de repede se încarcă
- **Largest Contentful Paint**: încărcarea conținutului principal
- **Cumulative Layout Shift**: stabilitatea layout-ului

## 🔧 Setup în 2 minute:

### Pas 1: Activează Vercel Analytics
1. Mergi la https://vercel.com/dashboard
2. Selectează proiectul "website-raffaella-beauty"
3. Click pe tab-ul "Analytics"
4. Click "Enable Analytics"

### Pas 2: Verifică datele
1. Așteaptă 24h pentru date inițiale
2. Vei vedea traficul în timp real
3. Metrics de performanță automat

## 📊 Dashboard-uri disponibile:

### 1. Overview (Prezentare generală)
- **Page views**: vizualizări totale
- **Unique visitors**: vizitatori unici
- **Bounce rate**: rata de respingere
- **Session duration**: durata sesiunilor

### 2. Pages (Pagini)
- **Top pages**: cele mai vizitate pagini
- **Page views per page**: vizualizări per pagină
- **Unique visitors per page**: vizitatori unici per pagină
- **Bounce rate per page**: rata de respingere per pagină

### 3. Referrers (Referințe)
- **Direct**: trafic direct
- **Google**: trafic din Google
- **Social media**: trafic din social
- **Other websites**: trafic din alte site-uri

### 4. Countries (Țări)
- **România**: trafic din România
- **București**: trafic local
- **International**: trafic internațional
- **City breakdown**: detalii pe orașe

### 5. Performance (Performanță)
- **Core Web Vitals**: metrici Google
- **Speed Index**: viteza de încărcare
- **Time to Interactive**: timp până la interacțiune
- **Total Blocking Time**: timp de blocare

## 🚨 Alerts importante:
- **High bounce rate**: rata de respingere ridicată
- **Slow pages**: pagini lente
- **Core Web Vitals issues**: probleme performanță
- **Traffic drops**: scădere trafic
