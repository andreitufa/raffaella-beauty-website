# Vercel Editor - Editare Directă în Browser

## 🎯 Ce poți face:
- **Editezi fișierele** direct în browser
- **Vezi modificările** instant live
- **Nu ai nevoie** de Git sau Node.js
- **Acces de pe orice computer** cu internet
- **Deploy automat** la fiecare modificare

## 🔧 Setup în 2 minute:

### Pas 1: Accesează Vercel Editor
1. Mergi la https://vercel.com/dashboard
2. Selectează proiectul "website-raffaella-beauty"
3. Click pe tab-ul "Source"
4. Click "Edit with Vercel"

### Pas 2: Editează fișierele
1. Vei vedea toate fișierele în browser
2. Click pe orice fișier pentru a-l edita
3. Modifică codul direct
4. Click "Save" → deploy automat

## 📁 Fișiere importante de editat:

### Conținut (ușor de modificat):
- `components/About.tsx` → textul despre salon
- `components/Contact.tsx` → informațiile de contact
- `components/Services.tsx` → descrierile serviciilor
- `pages/*.tsx` → prețurile serviciilor

### Stiluri (dacă știi CSS):
- `globals.css` → culori, fonturi, stiluri
- `components/*.tsx` → className-uri Tailwind

### SEO (important):
- `components/SEO.tsx` → meta tags
- `components/StructuredData.tsx` → date structurate
- `public/sitemap.xml` → sitemap

## 🎨 Modificări comune:

### Schimbă textul:
1. Deschide `components/About.tsx`
2. Găsește textul pe care vrei să-l schimbi
3. Modifică între ghilimele
4. Save → deploy automat

### Schimbă prețurile:
1. Deschide `pages/EpilareDefinitiva.tsx`
2. Găsește array-ul `femeiItems` sau `barbatiItems`
3. Modifică valorile din `price`
4. Save → deploy automat

### Schimbă informațiile de contact:
1. Deschide `components/Contact.tsx`
2. Găsește `phoneNumber`, `email`, `address`
3. Modifică valorile
4. Save → deploy automat

### Schimbă imaginile:
1. Upload imaginea nouă în `public/assets/`
2. Modifică numele în fișierul corespunzător
3. Save → deploy automat
