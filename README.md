# Raffaella Beauty Studio Website 
 
Professional beauty services website built with React, TypeScript, and Vite. 
 
## Features 
- Responsive design 
- SEO optimized 
- Google Analytics integration 
- Google Ads conversion tracking 
- Structured data for search engines 
 
## Services 
- Epilare Definitiva 
- Extensii Gene 
- Tratamente Faciale 
- Laminare Gene 
- Scanare Ten 
 
## Tech Stack 
- React 18 
- TypeScript 
- Vite 
- Tailwind CSS 
- Framer Motion
